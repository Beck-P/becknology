# Sign fonts for the Blender scenes

Display typefaces for neon and lightbox signs (`assets_signs.py`), all from
[google/fonts](https://github.com/google/fonts) under the SIL Open Font
License 1.1 (`OFL.txt`; each font's copyright is in its own metadata):
Audiowide, Bungee, Dela Gothic One (Latin + Japanese), Monoton, Pacifico,
Righteous, Rubik Mono One, Russo One, Zen Dots. Used at render time only —
they are not shipped with the app.
