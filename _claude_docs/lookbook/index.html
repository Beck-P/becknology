What it takes

What's realistic, and in what order

All of this can be built. Some of it is engine work, done once and every world gets it. The rest is art, done for each thing. Here is how the pieces break down.

PieceWhat it takesSize
Light and finishThe grade by the hour, glow on lamps and windows, light shafts, cloud shadows, depth of field: engine effects like the ones on this page, added to the game once. Every world gets them, with no re-rendering.Small
WaterAn engine pass over every water surface: the sky's colour, mirrored reflections, depth, a foam line, glints, rain rings, ice. Each scene also renders the things that should reflect. The game's sea code already does part of this.Medium
Ground and natureRe-finish the Blender renders: no dot-grid dither, calmer colour steps, no lines drawn inside grass and dirt, curved edges. Trees, bushes, rocks and flowers become drawn sprites. Prove it on one test scene, then redo the ~25 outdoor scenes once.Medium–large
Shape of the landCliffs, terraces, waterfalls, streams and lookouts designed into each map. Mostly layout work in the scene scripts, world by world.Medium
BuildingsA kit of building parts drawn in code like the street above (roofs, walls, windows, doors, trim, each with snow and night versions), so every house can differ. The main buildings get their own details on top.Medium
PeopleThe layered system above (body, hair, outfit, hat, carried item, with colour swaps), replacing the 3D-rendered sheets. The bigger part is poses: the game also has fighting, climbing, skiing and sitting frames for every outfit. Pilot customisation comes with it, and dialogue portraits can follow.Medium–large
Postcard viewsA side-view panorama per place, drawn in code like the one above, shown when fishing, sitting or on the title screen.Small each

The order I'd do it in

  1. Pick the style. My vote is the third one at the top: hi-res pixel art with HD-2D light.
  2. Light and finish in the engine first. It lifts every world at once and costs the least.
  3. Water, everywhere: the single biggest jump in beauty.
  4. One test scene with every nature piece, worked on until it holds up next to Stardew. Then redo the outdoor worlds once, shaping the land as each one is redone.
  5. People: the layered sprites and the cast.
  6. Buildings, world by world, alongside step 4.
  7. Postcard views along the way, starting with fishing.

How this page relates to the game

These scenes are small frames drawn entirely in code, to show the look. The game's worlds are much bigger and are built from Blender renders, drawn sprites and code effects together. The light, water, weather and finish on this page carry straight over as engine effects. The trees, ground and buildings show the target the art has to hit.

One thing this page proves: the people and buildings here were drawn in code, not painted with an image model. So most of this art can be made directly in the repo, kept consistent, and given seasons and nights without anyone painting each version by hand.

Seasons, nights and weather are built in from the start here, because every world has to look right in all of them.
